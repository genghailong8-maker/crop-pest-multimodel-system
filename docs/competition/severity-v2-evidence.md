## Evidence hierarchy

1. Same disease/pest peer-reviewed evidence.
2. Authoritative agricultural, extension, or plant-protection source.
3. Validated analogous damage/severity scale.
4. project_operational_rubric — explicitly operational, never described as a national, industry, or universal scientific threshold.

## Audit conclusion

Evidence basis coverage is 16/16. No row claims a class-specific four-state numeric or national standard where none was verified. Evidence supports observable vocabulary; each class-level mild/moderate/severe boundary is therefore explicitly a project_operational_rubric pending a validated class-and-unit scale.
