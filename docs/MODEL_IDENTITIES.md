# 模型外部依赖身份

本公开源码候选不附带模型权重二进制。部署者须从权利人或项目授权的模型存储获取，并在使用前核验下列 SHA256。

| 用途 | 身份 | SHA256 |
|---|---|---|
| 植物专家 | E2 Plant5 / YOLO11s | `ef2fa27183aee6ea6296a669a408cf47ecd6094705218cb8dac90a7309d49567` |
| 昆虫专家 | Frozen YOLO26N | `e233fc1971f88288fabed8d37af32047f6d1cb643213d9de0ee61385666479ba` |
| 视觉上下文 | `openai/clip-vit-base-patch32`，记录的 revision `3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268` | `a63082132ba4f97a80bea76823f544493bffa8082296d62d71581a4feff1576f`（冻结记录权重文件） |

该 SHA 是身份校验值，不构成再分发授权。第三方权重的许可需由使用者按模型发行方条款单独确认。CLIP 仓库代码许可不自动授予权重或服务权利。
