## 训练与评价可复现性

冻结源码快照中没有可核实为 E2 P1 最终权重生产流程的完整训练源码、配置、固定划分和运行日志。工作区其他训练目录含多阶段候选实验，无法仅凭目录或文件名证明其生成上述 E2 权重；因此本公开副本没有导入这些未建立身份关系的实验代码，也不声称可以从公开文件完整重训 E2。

冻结文件和旧比赛文档包含更早 16 类主模型的历史指标（例如 833 张冻结验证集上的 P/R/mAP 指标）。这些数字属于旧主模型与旧评估口径，**不是 E2 Plant5 或 Frozen YOLO26N 的指标**，不能作为本版双专家的量化性能声明。冻结验收记录确认的是服务身份、指定权重 SHA、路由与用户验收；本公开整理没有重新跑训练或模型评估。

可复现的已公开部分包括正式类别映射、可公开的 24 张新增样本及标签、推理服务源码、依赖配置、知识/Severity/Treatment 数据和来源清单。训练重现仍需要权利允许的完整图像与标签、正式划分、训练配置、软件版本、随机种子和原始训练日志；当前缺失项不作推断。

## 软件环境身份

冻结运行记录中的检测环境为 Python 3.12.3、PyTorch 2.8.0+cu128、CUDA 12.8、Ultralytics 8.4.115；CLIP Context 运行记录为 Python 3.12.3、PyTorch 2.6.0+cpu、Transformers 4.48.3。复现时以仓库各服务的依赖声明和目标平台兼容性为准；上述版本是当时运行环境身份，不保证其他 GPU/驱动组合直接兼容。

## 评估声明

- E2、Frozen 指标：此公开副本没有可对该两套冻结权重进行逐项审计的完整官方评估结果，故不报告数值。
- CLIP：此仓库没有新的准确率评估结论；权重身份与真实服务状态不等于识别准确率验证。
- Web/系统：冻结报告记载用户已完成人工验收；这不是本次公开副本上的新运行测试。
- 历史 Phase 9 结果只可作为历史项目记录阅读，并须遵守上面说明的模型/数据集边界。
