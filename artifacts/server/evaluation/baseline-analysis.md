## 主要混淆

混淆矩阵轴定义为“行=预测、列=真实”，以下比例按真实类别归一化：

- 豆芫菁 → 芫菁：39.8%。
- 玉米锈病 → 玉米叶枯病：31.8%。
- 蝗总科 → 盲蝽科：31.5%。
- 番茄晚疫病 → 番茄细菌性斑点病：25.8%。
- 马铃薯早疫病 → 马铃薯晚疫病：24.2%。
- 盲蝽科 → 蝗总科：24.1%。
- 番茄细菌性斑点病 → 马铃薯早疫病、番茄斑枯病：各 20.4%。
- 玉米叶枯病 → 玉米锈病：20.0%。

早疫病/晚疫病冲突不仅出现在预测中，也出现在已隔离的官方完全重复、标签冲突样本中。因此第二轮首先应处理数据与定义边界，而不是单纯加大模型。

## 第二轮实验计划

1. 保持当前验证集永久锁定，不将新增数据放入既有验证集。
2. 优先补充并专家复核类别 5、3、7、1，记录来源和许可证；每类先达到约 200 张高质量训练图，再比较增益。
3. 针对早疫病/晚疫病、细菌性斑点病/斑枯病、芫菁/豆芫菁、盲蝽科/蝗总科建立成对 hard-negative 集。
4. E1：YOLO26n + 稀缺类重采样，隔离“数据增益”。
5. E2：YOLO26s 640，与 E1 使用完全相同数据，隔离“容量增益”。
6. E3：最佳模型提高到 960 输入，重点观察小虫和细粒度病斑定位。
7. E4：对四组高混淆类别增加检测框二阶段分类器；检测器负责定位，分类器负责细分。
8. 保留低置信度、Top-2 差值小于 0.12，以及弱类命中的人工复核规则；多模态模型只能补充证据，不能覆盖低可信视觉结果。

阶段验收建议：整体 mAP50-95 至少提升 0.025；类别 5 的 Recall 提升到 0.40 以上；类别 3、5、7 的 mAP50 各提升至少 0.10；强类 mAP50 不下降超过 0.03。
